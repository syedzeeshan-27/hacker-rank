## Rule-uncertain texts in sample_deletion_requests.csv

- case_08: rule = UNCERTAIN (deletion verb plus export/download words), offline fallback DELETION; the sample answer treats it as a deletion case. Text: "I closed my account, but an old “download your data” link still works. Please delete that export file as well."

## Suggested custom evaluation cases from this review

- Marketing-only removal (the DOUBTFUL row): expected NOT_APPLICABLE per the problem statement; checks that "remove" alone does not trigger deletion.
- Negated deletion words ("I am not asking for deletion", "not a request to erase it", "don't delete"): expected NOT_APPLICABLE; checks that keep wins.
- Deleting one leftover copy after the account is gone (the sample case above): expected deletion handling.
- "Please apply the correct treatment" inside a deletion text: *correct* must not read as a correction request.
